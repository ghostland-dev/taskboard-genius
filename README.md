# TaskBoard

Task management app with analytics and team views.

## Features

- Tasks and calendar
- User analytics
- Account, export and notification settings

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Supabase

## Getting Started

```bash
git clone https://github.com/ghostland-dev/taskboard-genius.git
cd taskboard-genius
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
